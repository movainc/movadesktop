Installing

Up and running in a minute

macOS

  1. Open the .dmg and drag mova into Applications.
  2. Open mova from Applications. If macOS says it can't check the developer, right-click mova → Open, then confirm.

Windows

  1. Run the -setup.exe installer.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Open mova from the Start menu.

Linux

  1. AppImage: chmod +x mova_*.AppImage, then run it.
  2. Debian/Ubuntu: sudo apt install ./mova_*_amd64.deb

Then sign in with Google — a short tour will show you around. Need help? Read the getting started guide.

Requirements

Light on your computer

mova is a native app built with Tauri, so it's small and quick to start. macOS 11 or later on Apple Silicon, Windows 10/11 64-bit with WebView2 (included in Windows 11), or a recent 64-bit Linux with WebKitGTK.
